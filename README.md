# 膝关节康复角度波形分类系统

本系统是一个专门为膝关节康复训练设计的智能角度识别工具，能够自动识别不同膝关节弯曲角度产生的波形数据，并进行精确分类。适用于医疗康复机构、研究单位以及个人康复训练辅助。

## 🌟 功能特点

1. **多格式支持**：支持CSV、Excel(XLS/XLSX)、TXT文本文件格式
2. **智能特征提取**：自动识别波形中的周期性特征，忽略噪声干扰
3. **高精度分类**：采用先进的MG-Transformer深度学习模型
4. **丰富可视化**：提供桌面应用和Web小程序两种可视化界面
5. **详细结果输出**：不仅输出最匹配的角度类别，还提供各类别的匹配概率
6. **AI智能分析**：集成AI分析引擎，提供专业的数据解读和建议
7. **学术级界面**：界面美观，适合制作高质量的学术出版物插图

## 📁 数据格式要求

系统支持多种数据格式：

### 支持的文件类型：
- `.csv` - 逗号分隔值文件
- `.xlsx` / `.xls` - Excel电子表格
- `.txt` - 空格分隔文本文件

### 数据格式规范：
文件应至少包含两列数据：
1. **时间列**：第一列通常为时间数据（系统会自动归一化处理）
2. **电流/电阻列**：包含波形数据的列，支持多种命名方式：
   - 英文：`Current(A)`、`Resistance`、`R`等
   - 中文：`电流`、`电阻`、`相对时间`等

示例：
```
相对时间(s)  电阻(R)
0            6552
0.1          6552.4
0.2          6553.1
...
```

### 新的数据目录结构：
现在支持更简单的文件结构，直接将不同角度的文件放在同一文件夹下，
文件名即为类别名：

```
waveform_data/
├── 0-30.xlsx
├── 30-60.xlsx
├── 60-90.xlsx
└── ...
```

## ⚙️ 技术细节

### 1. 数据处理流程

1. **文件解析**：自动识别并读取不同格式的数据文件
2. **时间归一化**：将时间列数据归一化到0-1区间
3. **特征增强**：提取7维增强特征以提高分类准确率
4. **标准化处理**：对数据进行标准化以加快模型收敛

### 2. 特征工程技术

为了更好地处理周期性波形并降低噪声影响，我们采用了以下特征增强技术：

1. **原始电流值** - 直接使用电流/电阻信号
2. **一阶差分** - 表征信号的变化率
3. **二阶差分** - 表征信号的加速度
4. **滑动均值** - 平滑局部波动，提取趋势
5. **峰值特征** - 提取波形的最大值
6. **谷值特征** - 提取波形的最小值
7. **峰值位置** - 表征波形的时间特性

### 3. MG-Transformer模型架构

本系统采用MG-Transformer（Multi-scale feature extraction with Graph-based attention Transformer）架构：

1. **CNN模块**：
   - 多层卷积神经网络提取波形的局部特征
   - 捕捉波形中的突变点和细节信息

2. **位置编码**：
   - 为序列数据添加位置信息
   - 使用正余弦函数生成位置编码

3. **Transformer编码器**：
   - 多头自注意力机制建模波形的全局时序依赖关系
   - 前馈网络进一步提取高级特征

4. **多尺度池化策略**：
   - 结合平均池化、最大池化和最小池化
   - 全面表征波形的整体特征

5. **分类器**：
   - 全连接层进行最终分类
   - 输出各类别的概率分布

### 4. 数学表达式

#### Transformer自注意力机制：

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

其中：
- $Q$ 是查询矩阵（Query）
- $K$ 是键矩阵（Key）
- $V$ 是值矩阵（Value）
- $d_k$ 是键向量的维度

#### 多头注意力：

$$\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, ..., \text{head}_h)W^O$$

其中：
- $\text{head}_i = \text{Attention}(QW_i^Q, KW_i^K, VW_i^V)$
- $W_i^Q \in \mathbb{R}^{d_{model} \times d_k}$, $W_i^K \in \mathbb{R}^{d_{model} \times d_k}$, $W_i^V \in \mathbb{R}^{d_{model} \times d_v}$, $W^O \in \mathbb{R}^{hd_v \times d_{model}}$ 是可学习参数

#### 层归一化：

$$\text{LayerNorm}(x) = \alpha \odot \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} + \beta$$

其中：
- $\mu$ 和 $\sigma^2$ 是均值和方差
- $\alpha$ 和 $\beta$ 是可学习的缩放和平移参数
- $\epsilon$ 是防止除零的小常数

#### 位置编码：

$$PE_{(pos,2i)} = \sin\left(\frac{pos}{10000^{2i/d_{model}}}\right)$$
$$PE_{(pos,2i+1)} = \cos\left(\frac{pos}{10000^{2i/d_{model}}}\right)$$

其中：
- $pos$ 是位置
- $i$ 是维度

### 5. 模型训练参数

- 损失函数：交叉熵损失
- 优化器：AdamW
- 学习率：1e-4
- 权重衰减：5e-4
- 梯度裁剪：最大范数为1.0

## 📊 性能优化

1. **周期特征提取**：系统能够自动识别波形中的周期性特征，即使单个文件包含多个周期也能正确处理
2. **噪声抑制**：通过差分、平滑等技术降低噪声对分类准确性的影响
3. **多尺度特征融合**：结合CNN和Transformer的优势，既关注局部细节又考虑全局依赖关系
4. **时间归一化**：自动处理不同采样频率的数据

## 🛠️ 故障排除

### 常见问题

1. **"找不到电流或电阻列"错误**
   - 确保数据文件中包含名为"电流"、"电阻"、"Current"、"Resistance"等相关列名
   - 系统不区分大小写

2. **"不支持的文件格式"错误**
   - 确保文件扩展名为.csv、.xlsx、.xls或.txt
   - 检查文件是否损坏

3. **训练过程很慢**
   - 减少训练轮数（epochs）
   - 减少数据量或使用更强的硬件
